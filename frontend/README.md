# Lifestyle Frontend

A modern lifestyle and wellness website built with React, TypeScript, Vite, Tailwind CSS, and React Router. The project includes a polished landing page, category pages, blog-style content sections, testimonials, newsletter signup, and a chatbot-style UI component.

## Features

- Responsive homepage with hero carousel
- Dedicated pages for Women, Men, About, Contact, Blog, Sign In, and Sign Up
- Wellness-focused content cards and article previews
- Newsletter and testimonial sections
- Modern UI built with Tailwind CSS

## Tech Stack

- React 19
- TypeScript
- Vite 7
- React Router DOM
- Tailwind CSS 4

## Getting Started

1. Navigate to the frontend folder:
   `bash
   cd frontend
   `
2. Install dependencies:
   `bash
   npm install
   `
3. Start the development server:
   `bash
   npm run dev
   `

## Available Scripts
pm run dev - Start the local development server
pm run build - Create a production build
pm run preview - Preview the production build locally
pm run lint - Run ESLint checks

## Project Structure

- src/components - Reusable UI components
- src/pages - Page-level views for the app
- src/App.tsx - Main routing and page layout
